# Windows environment gotchas

- Git Bash paths are POSIX (`/c/Users/...`); native Windows programs (vim.exe, python, git internals) use `C:/Users/...`. Canonicalize with `pwd -P` before comparing paths; convert with `cygpath -m` before passing a path to a native exe.
- "Used by another process" on a directory move/rename is often a background process whose current directory is inside the folder, with no open files. Find holders by process CWD (PEB `CurrentDirectory` via `NtQueryInformationProcess`), stop the parent daemon before its children, and re-scan before retrying.
- pnpm `UNKNOWN: unknown error, open '…node_modules\…\package.json'` or "The path cannot be traversed because it contains an untrusted mount point" means Windows refuses to follow pnpm's directory junctions (since the 2026-09-22/23 updates). Deleting and reinstalling doesn't fix it. Put `node-linker=hoisted` in a git-excluded `.npmrc` next to `package.json`, then delete `node_modules` and reinstall. Stop dev servers first: a running Vite holds files in `node_modules`.
